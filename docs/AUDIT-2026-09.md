## Method

One read-only reviewer per repository, in parallel, no paid or external calls.
This repository's reviewer ran the offline suite with a throwaway attester key
and traced the attestation body against the verification snippets in the
README. On top of that, one deterministic check across all six: no `.env`
tracked at any point in history, `.gitignore` covering it, zero secret
patterns, zero `pull_request_target`.

Every HIGH finding was verified in the code before it was written down.

## Answer to the briefing's item 1 (does not change code)

The briefing for the jury's finding asks first: **which file does Railway run
in production?** `package.json` has `"start": "tsx src/server.ts"`, and there
is no `railway.json`, `Procfile` or `Dockerfile` overriding it. So production
serves `GET /verify` behind the daily budget; `demo/paid-endpoint.ts` is not
exposed. In the briefing's own words: design debt, not a fire. The fix stands;
the urgency does not.

## Medium and low, apply-only (frozen)

- [ ] The README's Python snippet uses `json.dumps` without `ensure_ascii=False`; verification breaks on the first SDN name with a diacritic (`funding.label` and `reasons[0]` are inside the signed body). Fix the snippet; add a test with a non-ASCII label.
- [ ] `kyaGate()` does not validate its configuration on mount (see pattern 2). Call `attesterAccount()` when the middleware is built, and correct `docs/ARCHITECTURE.md`.
- [ ] The pacing queue has no cap and no deadline; the 8 s timeout starts after it. Worst case 125 s in the queue while the UI gives up at 90 s. One shared `AbortSignal` per verify.
- [ ] Critical paths without tests: the gate's 503 fail-closed, the daily budget, the 400 before any I/O, the 404 with no fixture.
- [ ] No CORS on `/verify` (public by design) and no security headers on the UI.
- [ ] A wrong EIP-55 checksum is accepted and silently rewritten.
- [ ] `NoFixtureError` enumerates the fixtures in the 503 `detail` (low; the server exposes fixtures on purpose elsewhere).
- [ ] The attestation's `address` comes from the fixture file, not from the validated input: a fixture whose `history.address` diverges would sign a different address. Latent.
- [ ] README: in-memory counters reset on redeploy (only `ARCHITECTURE.md` says so); `npm i` where CI uses `npm ci`.
- [ ] The merge commit `3baa5b3` carries `claude/` in the branch name, against `CLAUDE.md`. Future branches without a tool prefix, or squash with a manual title.

## Dependencies

against this tree: 2 high, 30 moderate. The highs are axios 1.0.0 to 1.17.0,
reached through `@coinbase/cdp-sdk`, a dependency of `x402-express`; the
advisories postdate the 2026-09-05 pass above, which is why it recorded zero

item 15 of `DECISIONS.md`. The moderates ride the `x402` → wagmi →
`@walletconnect` chain and leave only through a breaking downgrade of
`x402-express` to 0.4.1, which stays undone; Dependabot (item 12) handles
them upstream.

## What holds up

- Secret hygiene is clean in the tree and the history.
- `verify.ts` is the single orchestrator; the gate and the server share one
  pipeline, verified by import graph.
- The gate fails closed, before settlement, and says so in the response body.
- Thresholds are measured and reproducible (`scripts/calibrate.ts`); weights are
  chosen and labelled as chosen. The file that holds them says which is which.
- `DECISIONS.md` records corrections to the project's own earlier claims
  (D18/D19), which is rarer than it should be.
